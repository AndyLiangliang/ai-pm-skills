# WVFSL Prompt 模板

WVFSL 是一个把产品想法转化为可编码 Prompt 的框架：

- **W**hat：解决什么问题
- **V**ibe：什么感觉/风格
- **S**tack：技术栈
- **F**eatures：核心功能
- **L**imit：明确不做

## 模板结构

```markdown
# [产品名] — Vibe Coding Prompt

## What（解决什么问题）
- 目标用户：
- 核心痛点：
- 成功标准：

## Vibe（感觉与风格）
- 视觉风格：
- 交互风格：
- 语气调性：
- 参考产品：

## Stack（技术栈）
- 前端：
- 后端：
- 数据库：
- AI 模型/API：
- 部署：

## Features（核心功能）
- 功能 1：
- 功能 2：
- 功能 3：

## Limit（明确不做）
- 不做：
- 不在 MVP 里：
- 后续版本考虑：
```

## 变成一段可复制的 Prompt

把上面的内容整理成一段自然语言：

```text
请帮我构建一个 [产品名]，这是一个面向 [目标用户] 的 [产品类型]，解决 [核心痛点]。

产品风格：[视觉风格] + [交互风格]，参考 [参考产品] 的感觉。

技术栈：[前端] + [后端] + [数据库] + [AI 模型/API]，部署到 [部署平台]。

MVP 必须包含以下功能：
1. [功能 1]
2. [功能 2]
3. [功能 3]

明确不做：
- [不做 1]
- [不做 2]

请先生成项目目录结构，然后逐步实现 MVP 功能。每一步完成后向我汇报。
```

## 注意事项

- Limit 部分必须具体，避免范围蔓延。
- Vibe 部分要给出可感知的风格词，不要抽象。
- Stack 部分要给出明确的技术选择，不要列出多个选项让 AI 猜。
